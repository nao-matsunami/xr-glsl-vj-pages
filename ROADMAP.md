# Pipeline Roadmap

The project started as a GLSL/WebGL sample site. Additional video-generation pipelines will be added in this order:

1. Canvas 2D
2. Three.js
3. SVG / CSS animation
4. Python / Pillow / OpenCV
5. Blender
6. TouchDesigner / Resolume-oriented workflow

Each pipeline should support:

- a lightweight browser sample on GitHub Pages
- deterministic loop timing
- `data/drops.json` metadata
- a path toward Mac mini fixed-FPS rendering for saleable MP4 / alpha MOV packs
